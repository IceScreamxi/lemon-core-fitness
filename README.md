# Lemon Core Fitness Hub
## 🏋️ Online Gym Registration System

Lemon Core Fitness Hub is a modern and easy-to-use website designed to provide customers with a convenient way to register for gym membership online.

The website simplifies the registration process by allowing prospective members to enter their information through an accessible online form. Registration details can then be organized and stored digitally, making the process more efficient for both customers and the gym.

### ✨ Features

* 📝 Easy online membership registration
* 👤 Simple and user-friendly registration form
* 📱 Responsive design for desktop and mobile devices
* 📊 Digital storage of registration information
* ☁️ Google Sheets integration for member data
* ⚡ Fast and convenient registration process
* 🔒 Secure handling of sensitive configuration and API credentials

### 🎯 Purpose

This project was created to simplify the registration process for Lemon Core Fitness Hub and reduce the need for manual data entry. It provides members with a convenient way to register while helping the gym maintain organized digital records.

### 🛠️ Technologies Used

* Next.js
* React
* TypeScript
* Google Sheets API
* Vercel
* GitHub

### 🚀 Deployment

The website is designed to be deployed online using Vercel and connected to a GitHub repository. Environment variables are used to securely store API credentials and other sensitive configuration values.
